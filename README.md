# spends.nl

The public website for Spends, an iOS budgeting app.

Static HTML and CSS, no framework and no build step. Cloudflare Pages serves this
repository at [spends.nl](https://spends.nl); the custom domain comes from `CNAME`.

`privacy.html`, `terms.html` and `support.html` are linked from inside the app, so
those filenames must not change.
