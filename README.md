# spends.nl

The public website for Spends, an iOS budgeting app.

Static HTML and CSS, no framework and no build step. GitHub Pages serves this
repository (public, source: `main` branch, root) at [spends.nl](https://spends.nl);
the custom domain is set via the `CNAME` file and the repository's Pages settings.

`privacy.html`, `terms.html` and `support.html` are linked from inside the app, so
those filenames must not change.
